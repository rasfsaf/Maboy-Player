# Maboy Player

Личный музыкальный плеер для Windows и Android. В одной библиотеке можно держать свои аудиофайлы и треки, добавленные по ссылке на YouTube, собирать плейлисты и продолжать слушать музыку на другом устройстве.

## Почему я его создал

Меня забанили в Spotify. В какой-то момент доступ к моей музыке стал зависеть от решения сервиса, на которое я никак не мог повлиять. Я не хотел снова собирать библиотеку внутри чужого приложения и однажды потерять её вместе с аккаунтом. Так появился Maboy: плеер, в котором я сам решаю, что добавить, как разложить треки и где их слушать.

## Зачем пользоваться Maboy

- **Одна библиотека на компьютере и телефоне.** Плейлисты, очередь, избранное и история синхронизируются между Windows и Android. Изменения, сделанные без сети, отправляются после восстановления соединения.
- **Свои файлы рядом с музыкой из YouTube.** Плеер находит аудио на устройстве; треки из YouTube можно добавлять по ссылке. Не нужно вести два отдельных списка музыки.
- **Управление воспроизведением под себя.** Есть ручная очередь, перемешивание, повтор и эквалайзер с готовыми и пользовательскими настройками.
- **Музыка остаётся доступной без сети, если файл есть на устройстве.** Локальные аудиофайлы воспроизводятся напрямую. Для треков по ссылке требуется доступное аудио; одна лишь синхронизация списка не скачивает всю музыку на телефон.

Maboy нужен тем, кому удобнее собирать собственную музыкальную библиотеку, чем подстраивать её под каталог и правила одной платформы. Для синхронизации между устройствами нужен аккаунт Maboy и соединение с сервером.
