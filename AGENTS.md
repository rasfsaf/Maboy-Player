# Maboy Project Agent Directives & Rules

## Правило сборки и деплоя
1. **Сборка серверных компонентов выполняется на VPS (`happ-germany`):**
   - Все изменения серверного кода (`server/`) должны быть развёрнуты на VPS в каталоге `/opt/maboy/server` и применены через `docker compose up -d --build`.
   - Локальный запуск используется только для модульных тестов `pytest`.

2. **Сборка клиентских бинарников (Windows & Android):**
   - Свежие скомпилированные релизные бинарники (`maboy.apk` и `maboy.exe` вместе с необходимыми DLL и папкой `data/`) **ОБЯЗАТЕЛЬНО** и **ВСЕГДА** должны копироваться в корень репозитория (`c:\Users\0SLEK\Desktop\Maboy Player\`).
   - Скрипт `build.ps1` должен гарантировать автоматическое развёртывание готовых бинарников в корень после каждой сборки без ручных действий.
