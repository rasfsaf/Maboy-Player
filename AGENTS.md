# Maboy Project Agent Directives & Rules

## Правило сборки и деплоя
1. **Релизные бинарники (`maboy.exe` и `maboy.apk`) ВСЕГДА должны быть в корне репозитория:**
   - После любой клиентской сборки свежие файлы `maboy.exe` (вместе с DLL и `data/`) и `maboy.apk` **ОБЯЗАТЕЛЬНО** и **ВСЕГДА** размещаются в корне (`c:\Users\0SLEK\Desktop\Maboy Player\`).
   - Скрипт `build.ps1` по умолчанию собирает обе платформы (`-Platform all`) и гарантирует актуальность обоих файлов в корне.

2. **Распределение сборки (VPS vs Локально):**
   - **Android APK**: собирается **ИСКЛЮЧИТЕЛЬНО на VPS (`happ-germany`)** в Docker (`ghcr.io/cirruslabs/flutter:stable`), чтобы не нагружать процессор и память локального компьютера разработчика («комп не задыхается»). Готовый `maboy.apk` автоматически скачивается в корень.
   - **Серверная часть**: собирается и перезапускается **на VPS (`happ-germany`)** через:
     ```bash
     cd /opt/maboy/server && docker compose -p maboy up -d --build
     ```
   - **Windows EXE (`maboy.exe`)**: собирается локально через Flutter/MSVC (быстрая компиляция без эмуляторов и тяжелых демонов) и копируется в корень.
